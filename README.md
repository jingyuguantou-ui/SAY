# 吵架训练场

模拟现实场景的吵架话术训练游戏。练完就能用。单文件 HTML，零依赖，手机/电脑通用。

![](https://img.shields.io/badge/%E9%9B%B6%E4%BE%9D%E8%B5%96-HTML-green) ![](https://img.shields.io/badge/%E6%89%8B%E6%9C%BA-%E9%80%82%E9%85%8D-blue)

## 快速开始

浏览器直接打开 [`index.html`](./index.html)。

**手机**：把 `index.html` 发到手机 → 用浏览器打开。输入框固定底部，适配刘海屏和软键盘。

## 玩法

- **6 大 BOSS**：画饼老板、催婚亲戚、阴阳同事、抠门房东、无理客户、PUA 大师（隐藏关）
- **三维评分**：攻势 / 逻辑 / 体面 —— 战斗中只飘伤害数字，**结算时才出完整复盘**
- **7 大机制**：
  - 连招（连续好回合伤害 ×2）
  - 话术牌（按等级解锁，每局随机 3 张）
  - BOSS 二阶段（半血狂暴）
  - 星级段位（青铜 → 王者）
  - 图鉴（收集最强回击 + 败北语录）
  - 每日挑战（每日一个 Boss + 特殊规则，双倍奖励）
  - 经验等级（升级解锁卡牌/Boss/称号）

## AI 模式（可选）

不填 Key 也能玩（关键词评分）。接入免费大模型后：

1. 打开 [open.bigmodel.cn](https://open.bigmodel.cn) 注册 → API Keys → 创建
2. 游戏首页 →「AI 设置」→ 粘贴 Key → 保存并测试

使用 [智谱 GLM-4-Flash](https://open.bigmodel.cn)（免费、国内直连）：

- BOSS 根据你的话**动态回击**（不是固定台词）
- AI 裁判评分 + 有梗评语
- 结算时生成**本局专属**推荐话术

Key 只存在你自己的浏览器 localStorage，不上传任何服务器。

## 存档

段位、等级、图鉴、战绩存在浏览器 `localStorage`，换浏览器/手机不互通。
